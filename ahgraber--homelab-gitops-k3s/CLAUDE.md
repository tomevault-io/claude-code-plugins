# homelab-gitops-k3s

> Update docs/renovate.md in sync with changes to renovate configuration.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/homelab-gitops-k3s/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

Update docs/renovate.md in sync with changes to renovate configuration.

Renovate configuration can be validated with

```sh
npx --yes --package renovate -- renovate-config-validator
```
