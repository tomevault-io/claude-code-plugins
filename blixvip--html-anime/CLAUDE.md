# html-anime

> Draw an html-anime film in code when the user pastes a sheet or asks for an anime made as HTML.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/html-anime/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:


Follow AGENTS.md. Read the five skills in `skills/` before drawing. The sheet is the brief.
