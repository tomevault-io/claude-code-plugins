# Cloudinary Account Provisioning Go SDK

Speakeasy-generated Go SDK for the Cloudinary Provisioning and Permissions APIs.

## Architecture

- **Generated code** (`cldprovisioning/`): regenerated by `speakeasy run` — do NOT edit
- **Custom hooks** (`cldprovisioning/internal/hooks/`): manually maintained — safe to edit (auth, config)
- **Config** (`.speakeasy/workflow.yaml`, `cldprovisioning/.speakeasy/gen.yaml`): controls generation behavior
- **Overlays** (`cldprovisioning/.speakeasy/speakeasy-modifications-overlay.yaml`): OpenAPI schema modifications

## Key commands

- `speakeasy run` — regenerate SDK from OpenAPI schema
- `go build ./cldprovisioning/...` — build the package
- `go test ./cldprovisioning/...` — run tests

## SDK resources

ProductEnvironments, Users, UserGroups, AccessKeys, BillingUsage, Roles, Principals, CustomPolicies, EffectivePolicies, SystemPolicies, Public
