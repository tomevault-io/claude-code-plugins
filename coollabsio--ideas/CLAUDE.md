# Project Instructions

Use Bun for JavaScript/TypeScript package management and scripts.

- Install deps with `bun install`.
- Add deps with `bun add <package>`.
- Run package scripts with `bun run <script>`.
- Prefer Bun over npm, yarn, or pnpm unless a task explicitly requires otherwise.
