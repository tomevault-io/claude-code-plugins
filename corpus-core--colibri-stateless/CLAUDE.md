# always-build

> Code Änderungen sollten immer durch bauen des Projektes mit cmake --build build/default überprüft werden.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```

```

Or copy the instructions below directly into your CLAUDE.md:


Code Änderungen sollten immer durch bauen des Projektes mit cmake --build build/default überprüft werden.
