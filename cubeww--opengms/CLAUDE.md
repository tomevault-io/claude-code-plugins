# opengms

> Build a modern GameMaker Studio 1.4 project editor for `.project.gmx` projects using Electron. The current development target is Windows.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/opengms/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

Build a modern GameMaker Studio 1.4 project editor for `.project.gmx` projects using Electron. The current development target is Windows.

The local `./references` directory contains useful documentation and sample projects for understanding the project format. It is excluded from Git and must not be committed.

Keep the project structure simple. Do not add tests; verification is handled by the user. Use short, clear, and direct names in the code.

Implement the editor UI in English. Localization, themes, and plugins are planned for future development.
