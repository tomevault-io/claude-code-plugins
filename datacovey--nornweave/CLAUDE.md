# performance-optimization-rule

> Rules to optimize performance of React and TypeScript components.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/performance-optimization-rule/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

- Optimize React component rendering using memoization techniques (e.g., React.memo).
- Avoid unnecessary re-renders.
- Lazy load components and images when possible.
- Use efficient data structures and algorithms.
