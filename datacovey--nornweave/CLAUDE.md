# ui-and-styling-rule

> Guidelines for UI and styling, focusing on Tailwind CSS and Shaden UI best practices.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/ui-and-styling-rule/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

- Utilize Tailwind CSS utility classes for styling components.
- Follow Shadcn UI component guidelines and best practices.
- Ensure UI is responsive and accessible.
