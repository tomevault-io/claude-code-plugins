# no-cursor-attribution

> Never add Cursor attribution trailers to git commits or PRs

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/no-cursor-attribution/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:


# No Cursor attribution

Never add any of these to commit messages, PR bodies, or code comments:

- `Co-authored-by: Cursor <cursoragent@cursor.com>`
- `Made-with: Cursor`
- Any other Cursor attribution / trailer

When creating commits or pull requests, use only the requested message/body content.
