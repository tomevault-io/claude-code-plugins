# file-organization

> Defines the file organization structure for TypeScript projects, emphasizing modularity and separation of concerns.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/file-organization/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

- Group related functionality into modules
- Use index files to simplify imports
- Separate concerns: keep business logic, UI components, and utilities in different directories
