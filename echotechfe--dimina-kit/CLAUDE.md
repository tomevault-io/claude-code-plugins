# dimina-kit

> Applies to every pull request in this repository.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/dimina-kit/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Copilot code review — dimina-kit

Applies to every pull request in this repository.

## Mandatory rules

You **must** read and **must** follow these files before every review. They are authoritative; if anything else conflicts with them, **those files win**. Skipping either makes the review invalid.

1. **`CLAUDE.md`** (repository root)
2. **`dimina/AGENTS.md`** (and any documents it requires, including `dimina/docs/Experience-Review.md`)

## Language

Review in Chinese when the PR is mostly Chinese; otherwise English.
