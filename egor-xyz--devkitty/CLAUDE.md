# devkitty

> Do all work in a Git worktree.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/devkitty/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Git worktrees

Do all work in a Git worktree.

Never edit files in the repo root.

Enter a worktree before the first edit.

Send build agents to the worktree path.

If work starts in the repo root, keep the work and move it to a worktree.
