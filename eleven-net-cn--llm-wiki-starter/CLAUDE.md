## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/llm-wiki-starter/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# <Wiki Name> — Claude Code Schema

@AGENTS.md

> This file imports the shared wiki schema from AGENTS.md via `@` directive.
> All shared rules (architecture, page format, workflows, constraints) live there.
>
> **Do not duplicate AGENTS.md content here.**
> Edit AGENTS.md for shared rules. Only add Claude Code-specific instructions below.
> If you find duplicated sections, delete them immediately.
>
> Ingest / lint / query operations modify wiki pages, never schema files.
