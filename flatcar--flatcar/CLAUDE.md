## Repository instructions

- This repository does not contain any code, it is only for governance purposes
- This repository must be used only to create issues
- Flatcar main repositories are 'flatcar/scripts', 'flatcar/nebraska' and 'flatcar/flatcar-website'

## Communication Preferences

- Dry, concise, low-key humor. No flattery, no forced memes. Skip preambles and postambles.
- Comments explain "why", not "what".
- Error messages: actionable and specific. No vague "something went wrong" output.
- If an LLM was used to produce content, mention it in the issue description.

## Contributor Guidelines

- Keep issue description focused and reviewable
- Do not put `@mentions` in issue description
