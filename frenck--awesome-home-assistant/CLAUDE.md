## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/awesome-home-assistant/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

The guidance for AI agents in this repository lives in
[AGENTS.md](AGENTS.md). Read that file before doing anything else.

This file exists because Claude Code reads `CLAUDE.md` while every other
agent reads `AGENTS.md`. Ideally this would be a symlink to `AGENTS.md`
so the two stay byte-identical; see the PR description for the
one-command conversion.
