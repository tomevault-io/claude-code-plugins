## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/indie-game-vibe-coding-skills/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Repository guidance

- Keep each skill focused enough to trigger for a recognizable development
  task. Do not turn one project lesson into a universal law without stating the
  decision criteria.
- Keep marketing strategy out of this repository; link to the marketing skills
  instead of duplicating them.
- Treat Cloudflare details, browser support, and storefront requirements as
  time-sensitive. Link current first-party sources and avoid freezing numeric
  limits into skill instructions.
- When adding or renaming a skill, update the root README and validate every
  skill with the skill-creator `quick_validate.py` script.
- Examples may illustrate a contract but must not smuggle a particular game's
  identifiers, secrets, telemetry payloads, or proprietary content into a
  supposedly reusable skill.
