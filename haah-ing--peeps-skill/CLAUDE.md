# skill-sync

> Keep dispatch and haah SKILL.md files in sync

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/skill-sync/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:


# Skill File Sync

`~/.claude/skills/dispatch/SKILL.md` and `~/.agents/skills/haah/SKILL.md` must be **exact copies** of each other at all times for compatibility.

When editing either file, always apply the same change to the other file immediately after.
