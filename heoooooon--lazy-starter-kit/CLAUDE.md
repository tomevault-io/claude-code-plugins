# lazy-starter-kit

> Follow the safety rules in `AGENTS.md`. In particular, never execute recursive `rm` directly; use `lazy-safe-rm` for a strict descendant of the current Git workspace.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/lazy-starter-kit/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Repository safety

Follow the safety rules in `AGENTS.md`. In particular, never execute recursive `rm` directly; use `lazy-safe-rm` for a strict descendant of the current Git workspace.
