# Agent instructions

Read **[CLAUDE.md](CLAUDE.md)** before doing anything in this repository. It
carries the project's constraints, layout, firmware findings, and open
problems in the form an agent needs.

Two things are worth knowing before you open it, because getting either wrong
does damage that is hard to undo:

- **Never commit firmware.** `NK.bin`, `EBOOT.bin`, ROM dumps and flash images
  are HumanWare's copyright and must not enter the repository. Check what you
  are staging.
- **Never contact HumanWare about this product,** and never present this
  project as theirs. This is an independent emulator, not affiliated with
  them. Do not write anything into the repository about any company's legal
  position on it.

Human-facing documentation is in [README.md](README.md); the reverse
engineering is written up in [docs/hardware.md](docs/hardware.md).
