## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/jev-browser-skill/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# jb

When the user wants to browse a site with jb, find an article or page, or
mentions jev browser, jb, or Jev Browser: read
[`skills/jev-browser/SKILL.md`](skills/jev-browser/SKILL.md) first and follow
it. The skill name is `jb-browser`. Generate a tight `--goal`, then run
`./bin/jb` from this repository root. From any other working directory, run
`skills/jev-browser/bin/jb` (follow symlinks). Do not also drive Chrome
DevTools MCP for that hunt.
