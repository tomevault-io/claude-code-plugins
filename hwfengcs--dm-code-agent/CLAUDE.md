# dm-code-agent

> - 除非用户特别要求使用其他语言，否则所有生成的文档、注释、代码说明都使用中文

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/dm-code-agent/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Claude Code 永久规则

## 语言偏好
- 始终使用中文与用户交流
- 除非用户特别要求使用其他语言，否则所有生成的文档、注释、代码说明都使用中文
- 代码变量名、函数名等可以使用英文，但注释和文档说明必须是中文
