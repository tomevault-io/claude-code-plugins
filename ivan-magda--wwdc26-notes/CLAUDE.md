# wwdc26-notes

> Public collection of WWDC 2026 session notes. One folder per session; the deliverable per session is `digest.md` — an LLM-synthesized summary.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/wwdc26-notes/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# CLAUDE.md

Public collection of WWDC 2026 session notes. One folder per session; the deliverable per session is `digest.md` — an LLM-synthesized summary.

## Critical gotchas

- `transcript.md` + `code.md` are Apple's © content; `digest.md` is this repo's own work.

## Per-session files

`sessions/{num}-{slug}/` contains `transcript.md` (Apple's verbatim transcript), `meta.md` (description, key topics, chapter summary), `code.md` (Code-tab snippets), and `digest.md` (the synthesized summary). Every file's frontmatter carries the source `url` back to developer.apple.com.
