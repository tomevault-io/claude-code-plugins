# swift-rule

> All new Ul must use SwiftUI.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/swift-rule/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:


All new Ul must use SwiftUI.
Follow the MVVM patter with ObservableObject.
Prefer structs over classes for data models.
Use lazy var for expensive computed properties in classes.
