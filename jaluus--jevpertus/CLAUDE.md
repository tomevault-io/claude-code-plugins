## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/jevpertus/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

Always use black and isort to format your code.
This means first you run isort to sort your imports, and then run black to format the code, in that order.

Dont ever write tests.

Dont use teh Pathlib, but os.path etc... for path manipulations.
