# bun-skills

> Skill names (the `name` field in `SKILL.md` frontmatter) must not exceed 64 characters.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/bun-skills/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Agent Instructions

## Skill naming
