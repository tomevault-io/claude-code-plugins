# Notes for AI agents

Momo accepts AI-assisted contributions on one condition: they say so.

- Begin every issue and pull request description you write with these two lines:

  ```markdown
  > [!WARNING]
  > AI-generated
  ```

- A security finding never goes into a public issue. Report it privately at
  <https://github.com/jp1337/momo/security/advisories/new>. Research is welcome and unpaid.
- How to work in this repository: [CONTRIBUTING.md](CONTRIBUTING.md) and [CLAUDE.md](CLAUDE.md).
