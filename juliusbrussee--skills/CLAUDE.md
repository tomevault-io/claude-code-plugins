## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/skills/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Agent Instructions

Read `CLAUDE.md` first. Same rules apply to all coding agents.

When editing skills:

- Keep changes narrow.
- Preserve frontmatter.
- Run `node scripts/verify-skills.mjs`.
- Update `README.md` when adding a major public skill category.
