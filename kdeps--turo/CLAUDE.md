# turo

> Point more. Token less.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/turo/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

Point more. Token less.

Install: `brew install kdeps/tap/turo` or download from https://github.com/kdeps/turo/releases

Usage: `cat CLAUDE.md | turo` or `turo file.md`. `turo gain` shows tokens saved.

See @./skills/turo/SKILL.md for integration details.
