# no-ai-coauthor

> Never add AI/Cursor Co-authored-by trailers on git commits

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/no-ai-coauthor/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:


# No AI Co-Authors on Commits

Never add `Co-authored-by` trailers for Cursor, Claude, Copilot, or any other AI assistant.

- Do not include yourself (or any AI) as a co-author in commit messages
- Do not add `Co-authored-by: Cursor <...>`, `Co-authored-by: Claude <...>`, or similar lines
- Commit messages must contain only the human author's intended subject/body, with no AI co-author trailers
