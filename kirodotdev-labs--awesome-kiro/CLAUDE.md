## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/awesome-kiro/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Agents

> This file is read by AI agents working on this repository. It contains rules and conventions that agents must follow.

## Linting

This repo uses `awesome-lint` in CI. Run it locally before pushing:

    npx awesome-lint

The only acceptable failure is `awesome-github` which fires on non-main branches.
