# swift-injection

> How to use Swift Inject

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/swift-injection/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

Add `import Inject` to the top of every view file.
Add `@ObserveInjection var inject` at the top of each view struct.
Add `.enableInjection()` to the end of each view body.
