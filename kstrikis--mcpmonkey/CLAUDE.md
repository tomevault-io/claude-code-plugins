# yarn-npm-packages-dependencies

> Installing dependencies using yarn

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/yarn-npm-packages-dependencies/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

Always use `yarn`, never `npm`.
Never modify package.json manually.
Always use `yarn` to add, remove, install, update, or downgrade packages.
