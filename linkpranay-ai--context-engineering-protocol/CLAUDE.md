# ult-repo-layout

> Register, resolve, and validate where a project's path-slots actually live via .layout-slots.yaml markers, so relocating a slot needs zero SKILL.md edits. Do NOT use for single-file lookups.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/ult-repo-layout/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:


# ult-repo-layout

This repository packages its capabilities as portable skills for AI
coding agents. Read `.github/skills/ult-repo-layout/SKILL.md` and follow it
when this rule applies.
