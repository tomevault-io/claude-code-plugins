# Vector Database Setup

Set up vector databases for AI applications. Pinecone, Weaviate, Qdrant, pgvector.

## Quick Start

```bash
npx ai-vector-db init pinecone
```

## What It Does

- Generate vector DB client code
- Support for major providers
- TypeScript ready
- Customizable dimensions and names

## Usage

```bash
# Generate client
npx ai-vector-db init pinecone
npx ai-vector-db init pgvector

# List providers
npx ai-vector-db providers

# Compare options
npx ai-vector-db compare
```
