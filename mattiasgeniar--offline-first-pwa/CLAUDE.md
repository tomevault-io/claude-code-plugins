# offline-first-pwa

> The rules live in [SKILL.md](SKILL.md), as one file with Claude Code skill frontmatter on top.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/offline-first-pwa/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# AGENTS.md

The rules live in [SKILL.md](SKILL.md), as one file with Claude Code skill frontmatter on top.

If your agent reads `AGENTS.md` rather than skills, copy `SKILL.md` into your own project and
reference it from there, or paste the sections you need. There's deliberately no second copy
of the rules in this repo: two copies drift.
