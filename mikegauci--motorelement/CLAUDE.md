# no-comments

> Prevent adding code comments unless explicitly requested

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/no-comments/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:


# No Code Comments By Default

- Do not add comments in code unless the user explicitly requests comments.
- This includes inline comments (`//`), block comments (`/* ... */`), and doc comments (`/** ... */`).
- Keep code self-explanatory through clear naming and simple structure instead.
