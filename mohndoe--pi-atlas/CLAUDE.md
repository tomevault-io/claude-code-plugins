## Agent skills

### Issue tracker

Issues live as Linear issues on the `pi-atlas` team. See `docs/agents/issue-tracker.md`.

### Triage labels

Six labels: `considering` (entry state), `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` at root + `docs/adr/`. See `docs/agents/domain.md`.
