# hulu-skill-pack

> This repository is a public collection of standalone personal skill packages.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/hulu-skill-pack/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Hulu Skill Pack

This repository is a public collection of standalone personal skill packages.

- Each skill lives in `skills/<lowercase-hyphenated-name>/`.
- `SKILL.md` is the canonical instruction file.
- Keep scripts and references inside the owning skill directory.
- Do not add private notes, credentials, personal data, internal URLs, or
  unreleased production workflows.
- Run the skill-local test before changing a skill.
