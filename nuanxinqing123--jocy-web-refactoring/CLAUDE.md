# 项目规则

- CSS部分, 如果没有特殊要求, 请默认使用Less

- 请严格遵守项目目录分层的设计
- 在Vue项目中, 组件 和 页面组件的代码全部放入components目录中, 或在对应页面目录下的components目录中
- 使用Vue3的标准和写法
