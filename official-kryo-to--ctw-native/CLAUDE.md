# Repository instructions

Read CONTRIBUTING.md before changing code.

- Keep edits within the requested scope and preserve other contributors' work.
- Keep engine (`port/src`), game (`port/game`), showcase and mod kit separate.
- Verify behavior from evidence and state assumptions.
- Never commit game assets, binaries, decompiler exports or extracted lookup tables.
- Run the relevant build and tests before finishing.
- Keep the two `ctw_plugin.h` copies identical and public APIs append-only.
