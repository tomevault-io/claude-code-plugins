# skillsets

> This extension bundles a collection of model-agnostic engineering and research skills.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/skillsets/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# skillsets

This extension bundles a collection of model-agnostic engineering and research skills.

For shared agent orientation and the full skill list, read the file below.

@./AGENTS.md
