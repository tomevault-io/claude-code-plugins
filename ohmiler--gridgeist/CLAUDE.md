## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/gridgeist/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Direction-decision behavioral harness

- This is a read-only behavioral evaluation of the response before any design edit.
- Inspect the local fixture files, including its product facts and existing behavior.
- Do not edit files, start a server, render the page, or perform implementation checks.
- Return only the next user-facing response you would send before changing the fixture.
- Do not assume an evaluation rubric or an expected visual answer.
