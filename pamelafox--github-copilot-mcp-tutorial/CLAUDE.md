```

```

Or copy the instructions below directly into your CLAUDE.md:


# Instructions for coding agents

This repository is a tutorial to help developers use MCP servers.

When working with GitHub, you should prefer using the GitHub MCP server versus the gh CLI.

Generally, if an MCP server is available to do a task, use the MCP server over other approaches.
