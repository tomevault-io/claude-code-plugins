# lose-it

> - Bump `version.txt` (semver) in every PR that changes `src/` — CI tags `v{version}` on merge and fails if the tag already exists.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/lose-it/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# AGENTS.md

- Bump `version.txt` (semver) in every PR that changes `src/` — CI tags `v{version}` on merge and fails if the tag already exists.
- Project is in alpha: stay on `0.x.x` (no `1.0.0` yet); bump patch for fixes, minor for behavior changes.
