## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/nvim-pi/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Personal Neovim Setup

- Push this repository regularly after major feature changes.
- Small minor edits do not need to be pushed immediately.
- Every project-owned non-test function must document whether it has been reviewed.
- Set new and changed project-owned function docstrings to `Reviewed: false.` Keep them unreviewed until Kyle reviews them in detail.
- Tests and external systems not owned by this project do not require review markers.
