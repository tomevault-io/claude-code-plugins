# pulse

> The Pulse CLI lives in this extension: `bin/pulse`. Gemini extensions

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/pulse/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

@./hooks/rules.md

The Pulse CLI lives in this extension: `bin/pulse`. Gemini extensions
are installed under `~/.gemini/extensions/<name>/`, so run it as
`~/.gemini/extensions/<name>/bin/pulse` wherever the rules or a Pulse
skill say `pulse`.
