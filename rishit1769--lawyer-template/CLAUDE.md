## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/lawyer-template/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

> [!IMPORTANT]
> Avoid rewriting published git history. Do not force push or
> rebase/amend/squash commits that are already pushed unless the repository
> owner has explicitly approved it.
>
> Keep the branch in a working state before pushing changes so downstream
> environments and collaborators receive a stable revision.
