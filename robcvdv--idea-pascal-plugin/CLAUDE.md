# idea-pascal-plugin

> Redirect output of terminal commands to "./.output.txt". Here you can read the output properly, because terminal access is limited. You are allowed to remove this file at will to easily read only the output you need.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/idea-pascal-plugin/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

Terminal commands:
Redirect output of terminal commands to "./.output.txt". Here you can read the output properly, because terminal access is limited. You are allowed to remove this file at will to easily read only the output you need.
