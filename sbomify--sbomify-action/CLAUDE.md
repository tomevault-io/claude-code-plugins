## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/sbomify-action/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

- NEVER create summary markdown files, documentation files, or README files unless explicitly requested
- Never edit any lockfiles manually. That includes poetry files and pyproject.toml.
- Always run unit/integration tests.
- Test coverage should always be 80% or more.
- When using `git`, always use it without a pager.
