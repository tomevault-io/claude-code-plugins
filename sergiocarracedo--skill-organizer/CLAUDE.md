# skill-organizer

> - Reserve yellow for interactive key hints and navigation help text.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/skill-organizer/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Local Notes

- Reserve yellow for interactive key hints and navigation help text.
- Do not use yellow for progress labels or spinner status text.
- Prefer the existing CLI palette for progress/status text: magenta/cyan/light-magenta before introducing new colors.
