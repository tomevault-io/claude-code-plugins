# advpl-specialist

> This repository is the `advpl-specialist` knowledge plugin for ADVPL/TLPP (TOTVS Protheus) development.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/advpl-specialist/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

@AGENTS.md

This repository is the `advpl-specialist` knowledge plugin for ADVPL/TLPP (TOTVS Protheus) development.
Slash commands live in `commands/`, specialized subagents in `agents/`, and the 18 reference skills
(consulted by both) in `skills/<name>/SKILL.md` plus their companion reference files.
