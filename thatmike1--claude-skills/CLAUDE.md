# claude-skills

> A collection of custom skills for Claude Code and compatible agent harnesses.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/claude-skills/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# claude-skills

A collection of custom skills for Claude Code and compatible agent harnesses.

The working instructions for this repo — structure, skill format, code conventions, the config pattern, the installer, the shared conversation parsers, and how to test scripts — live in [`CLAUDE.md`](CLAUDE.md). Read it before making changes; it is the single copy, so this file stays a pointer rather than a second version that drifts out of date.
