# coding-workflow-preferences

> description: Coding workflow preferences

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/coding-workflow-preferences/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:


---
description: Coding workflow preferences
globs: 
alwaysApply: true
---

-Focus on the areas of code relevant to the task
-Do not touch code that is unrelated to the task
-Write thorough tests for all major functionality
-Avoid making major changes to the patterns and architecture of how a feature works, after it has shown to work well, unless explicitly instructed but give the option to change code if you think it could be implemented better
-Always think about what other methods and areas of code might be affected by code changes
