# raula

> This repository (formerly `eslint-plugin-raula`) contains `eslint-plugin-raula`, `stylelint-plugin-raula`, `oxlint-plugin-raula` (experimental), the `create-next-app-with-raula` skill, and sample apps used to explain them.

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/raula/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Repository Instructions

This repository (formerly `eslint-plugin-raula`) contains `eslint-plugin-raula`, `stylelint-plugin-raula`, `oxlint-plugin-raula` (experimental), the `create-next-app-with-raula` skill, and sample apps used to explain them.

Before changing rule behavior, update the generated reference with:

```bash
pnpm run build --filter eslint-plugin-raula
pnpm run build --filter stylelint-plugin-raula
pnpm run build --filter oxlint-plugin-raula
pnpm run build --filter create-next-app-with-raula
```
