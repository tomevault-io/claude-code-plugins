# Codex Instructions

## Package Manager
- Use pnpm, not npm
- Never run `npm install` or create `package-lock.json`

## Git Commit Rules
- Never include Codex attribution in commit messages
- Never add "🤖 Generated with Codex" or similar phrases
- Write commit messages as if a human developer wrote them
- Follow conventional commit format (e.g., feat:, fix:, refactor:)
