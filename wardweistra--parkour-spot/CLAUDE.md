## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/read-flutter-docs/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:


Whenever you need the latest Flutter documentation use the Context7 MCP with the context7CompatibleLibraryID value of '/flutter/website'.
