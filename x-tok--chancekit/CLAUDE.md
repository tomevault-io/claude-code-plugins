# chancekit

> - 禁止自动执行 Release Actions

## Usage

Add this to your project's CLAUDE.md to activate this skill:

```
Read and follow the instructions in .claude/skills/chancekit/SKILL.md
```

Or copy the instructions below directly into your CLAUDE.md:

# Rules

- 禁止自动 Commit 和 Push
- 禁止修改任何原本 QQ 的行为和文件
- 禁止自动执行 Release Actions
