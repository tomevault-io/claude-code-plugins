# papercut-theater

> Tome by [zesonzhang](https://github.com/zesonzhang/papercut-theater) — distributed by [TomeVault](https://tomevault.io)

A demo app to show how a cross-device web application works. It provides a synchronized, dual-interface experience showcasing traditional Chinese Paper-cut art, allowing one device to act as the "Stage" display while another serves as the "Director" remote control.
