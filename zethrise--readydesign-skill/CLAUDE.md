# ReadyDesign

When building, restyling, or scaffolding UI, load and follow
`readydesign-skill`. Do not invent components or colors.
Install with `npx readydesign-skill` or `npm install readydesign-skill`.

- Codex / Antigravity: `.agents/skills/readydesign-skill/SKILL.md`
- Claude Code: `.claude/skills/readydesign-skill/SKILL.md`
- Invoke: `/readydesign-skill` or `$readydesign-skill`
